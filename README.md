2.0.2 版本更新使用的prompt：

```
现在我需要改进alt+8快捷键的功能，以下简称手牌区为hand，上阵区为lineup：

检索hand中最右边的一个 chessId 为 `21108081` 的卡牌（chessName是陈珪，记为卡牌A），将它上阵到lineup末尾并指定上阵前lineup最右侧的卡牌（记为卡牌B。注意与当前版本的区别，目前alt+8功能是指定最左侧的卡牌作为目标，需要修改为最右侧）作为技能目标。
步骤1执行完毕后，根据卡牌B的 chessId 分别做两种不同处理：
     - 若卡牌B的chessId不为`21103051`或`21103052`（金色/普通 的 丁奉），那么检索hand中是否存在卡牌B（依据卡牌B的goodsId匹配确定），如果存在则将卡牌B继续上阵到lineup末尾（无需指定技能目标），并遣散掉上阵区的卡牌A；否则无需执行操作（提示未找到卡牌B）
      - 若卡牌B的chessId为`21103051`或`21103052`（金色/普通 的 丁奉），那么检索hand中是否存在卡牌B（一局卡牌B的goodsId匹配确定），如果存在则将卡牌B继续上阵到lineup末尾并指定技能目标为卡牌C（检索lineup中是否存在chessId为`[21103061, 21103062, 21103171, 21103172]`其中之一的卡牌（金色/普通 的 凌统/孙尚香），如果存在则卡牌C为其中最右侧的卡牌，如果不存在则卡牌C 就是 卡牌B）；否则无需执行后续操作（提示未找到卡牌B）
```

## 261029

一些有一定coding基础的小伙伴，基于本人公开的方法，开发出全自动操作的脚本，我知道全自动脚本开发需要长时间的测试优化，我尊重大家的劳动成果，但过于张扬就会招致不必要的攻击，大家可以偷偷自己用去上分，而没有必要去嘲讽那些不会使用脚本的玩家。获得满足感的方式是多样的，人没有必要为自己招致无意义的麻烦，应当学会明智地做事，而非意气。

其实我希望有更多人加入到脚本开发中，这意味着我的教学是有意义的，确实帮助到其他人做出了一些看起来很 fantasy 的小玩意儿，倘若有一天能凑齐一桌 AI 脚本互战，也确实是一件挺有趣的事情。

## 260802更新摘要

mod文件夹里目前上传了一些没啥用的小功能，测试了若干欺骗后端的方法（如修改商店区/上阵区/手牌区的卡牌数据/攻防/buff，修改金币，修改上阵卡牌的buff），都只能对UI生效，但实际无法操作（比如可以凭空变出一张陈珪，这张陈珪可以上阵，甚至可以选择目标，但是没有后续，且无法累积飞将、触发羞花等；也可以凭空把营帐全部变成祢衡，但无法购买）。陆逊bug修复后，理论上目前不太能找得到作弊的方案，比较有趣的是如果把三连所需数量修改为2，则整局都无法再触发三连了（但是有2个同名出现时依然会有三连提示）。

目前所有功能其实已经足够用来收集操作数据，实现自走棋的 RL 训练，state（即shop/hand/lineup/coin/time） 和 action（buyAt/deployAt/sellAt/refresh/lock） 都是很明确的，有兴趣有时间的小伙伴可以尝试。

测了几局人机，快捷助手确实非常有用的，无论是三连控制，还是快速使用锦囊，以及上阵随征卡（可触发李广/杨玉环/李白），目前应该不存在任何卡顿问题。整体说确实有点失衡（尤其三连控制，这个理论上会被修，但只要不修就可以认为是游戏特性），但是大家都用也无所谓不公平了。

**本项目暂时处于archive状态，感觉没有太多合规的通用操作可以改进，深挖后端漏洞耗费精力性价比很低，大家有个性化的mod可以进行 Pull Request 分享。需要 PR 的小伙伴记得往 mod 中补充功能，直接往main提交即可，不用创建新分支，提交格式为`署名-功能名-版本号.js`，任何包含其他修改的PR均不会被接受。我会定期处理PR，爱你❤**

## 260728更新摘要


篡改猴脚本 https://web.sanguosha.com 一将成名

以Easy开头的.js文件直接在控制台使用，其余为.js文件为篡改猴脚本，发布的插件在`./release/`文件夹下面

- 三国杀自走棋快捷助手v1.0.0.js（作者：**鲁班大王，魏东离**）
  键盘控制的自走棋快捷助手
  - [1-6]**购买**：自动购买卡牌到手牌
  - [R]**刷新**：可模拟连点器效果，速度比连点器更快
  - [F]**锁定**
  - [Shift+1]**遣散手牌中最右侧卡牌**
  - [Shift+2]**自动使用最右侧锦囊**
    - 优先对营帐卡牌（第0个位置）使用，其次对上阵区域卡牌（第0个位置）使用，都失败则无事发生
	- 记得扔掉斗转（移除最左侧不谢），连续使用过拆时记得手动操作一下（不然就要拆场上的卡牌了）
	- 釜底抽薪目前无法使用，记得扔
  - [Alt+9]**遣散上阵区域最右侧卡牌**
  - [Alt+0]**上阵手牌中最右侧卡牌**
    - 可将不可上阵的卡牌上阵，如马元义、黄盖等（效果等同于牌面描述）
	- 有目标选择的当先上阵后会吞掉后续效果，如丁奉、司马徽等（有用处，比如不想丁奉移除牌的时候）
  - [Space]**跳过战斗**：
  - [Tab]**禁用/启用三连控制**
    - 可以实现合成金当先卡前多当先一次
	- 可以囤陈珪、随征卡、左慈
  - [Shift+R]**强制刷新UI** | 2x速度（测试不生效，本质是UI动画滞后的策略） | 事件+轮询刷新
    - 可将自动购买后不显示的卡牌显示出来
  - **陆逊小抄已禁用，不要想作弊**

- AutoBuyAndSell: 自动寻牌助手
  - 调整`timer = setTimeout(doNext, 200);`中设置间隔时间，测试如果间隔<=100，可能不够时间买全卡牌，最好设>=200的数值，慢一些但是稳定
- AutoRefresh.js: 自动刷新（连点器上位方案）
  - 这个想多快就多快，`interval`默认为0（无间隔）
- AutoUseSpell.js: 陆逊小抄（已删除，不影响游戏平衡） & 一键使用锦囊（ChessHelper中已经实现键控使用锦囊）
  - 一键使用锦囊目前unstable，因为锦囊变化太大，不同锦囊的使用参数区别大，目前用的是这样一套使用逻辑：
    - 优先尝试无参数调用（如先驱、洞烛这类直接使用的锦囊）
	- 如果失败则对营帐第一个格子使用（如过拆）
	- 如果失败尝试对场上第一个棋子使用（如桃、酒等）
	- 如果都失败，则卖掉锦囊
	- 可能出现的问题：如草船、三顾使用后需要手动选择一次（这种情况还没有处理），再比如连续使用过拆，营帐可能没有可以拆掉的对象
- SGSCheater.js: 三国杀打小抄（作者：小麦 & 孤独尊）
- TavernchessSkipBattle.js: 跳过自走棋战斗按钮
- TavernChessStats-0.4.3.js: 自走棋数据统计
- ChessHelper.js: 键盘控制的自走棋快捷助手
- EasyAutoRefresh.js: 执行后自动刷新1次
- EasyBuy.js: 自动购买卡牌
- EasyClick.js: 执行后启动页端连点器（跟随鼠标）
- EasyDeploy.js: 自动上阵操作（上阵卡牌的位置调整可自动化，但是没什么意义目前）
- EasyRefreshUI.js: 手动刷新UI（把手牌区没显示的卡牌刷出来）
- EasySelect3.js: 3选1框自动选择
  - 目前针对3选1装备是测试通过的，但针对卡牌/锦囊的3选1目前测试不能通过，待修
- EasySell.js: 自动遣散卡牌
- EasySkipBattle.js: 执行后跳过战斗
- EasyUseSpell.js: 脚本操作使用一张锦囊
